# Security Policy — C5-REAL Standard

This repository follows the Sovereign Architecture principles. Security vulnerabilities are treated with highest priority.

## Reporting a Vulnerability

Please report security vulnerabilities directly to:
- **Contact:** borja@babylon60.com (or security@babylon60.com)

Please DO NOT disclose vulnerabilities in public GitHub issues.
We confirm receipt within 24 hours and provide remediation within 72 hours.
